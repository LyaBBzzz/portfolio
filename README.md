# Portfolio | Klimanov D.

## Технологический стек

*   **HTML5:** Семантическая разметка, доступность, базовая интеграция мета-тегов для SEO.
*   **CSS3:** CSS-переменные (Custom Properties), Flexbox/Grid layouts, медиазапросы, CSS-трансформации и аппаратное ускорение.
*   **JavaScript (ES6+):** DOM манипуляции, работа с Canvas API, Intersection Observer API, событийная модель (в т.ч. debounce-оптимизации).

##  Как запустить локально

Проект не требует сложной сборки. Для запуска достаточно:

1.  Скачать проект на свой компьютер.
2.  Открыть файл `index.html` в любом браузере.

## Структура проекта

```text
portfolio
├── index.html      # Главная страница (разметка)
├── styles.css      # Основные стили, адаптив и анимации
├── script.js       # Вся JS логика (canvas, скролл, наблюдатели)
└── images/         # Медиафайлы (фото, превью проектов, 3D-ассеты)
```
